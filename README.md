# Tabula

Latin practice for Jenney's *First Year Latin*: sentences, vocabulary flashcards, forms, cases, tests, notes, and review.

## How it's built

The whole site is one file, `index.html`. All the styles, word lists, and code are inside it. To try it, open `index.html` in a web browser.

## Working on it together

- Before you start, make sure you have the latest version from GitHub.
- Try not to both change the same part of the site at the same time.
- Each saved change should have a short note saying what changed.

Progress such as streaks and starred words is saved in each person's own browser, so it is not shared through GitHub.
